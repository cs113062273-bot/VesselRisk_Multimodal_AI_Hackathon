# VesselRisk execution plan

Source priority: Track A.pdf > actual workbook > supplied design image > instruction.md (read as UTF-8). CODEX_MASTER_BRIEF.md is the execution contract. All supplied files were read before implementation.

1. Inspect data and official rubric; verify sources, winning submission materials, and anatomical asset licenses.
2. Build a strict schema and leakage guard; evaluate four tasks using nested repeated stratified CV. Compare logistic regression, random forest and XGBoost; choose model and calibration inside outer training folds. Persist out-of-fold predictions, curves, subgroup results, ablations, uncertainty, and exact artifacts.
3. Build a typed FastAPI service with validated complete patient input, real local/global model explanations, model agreement, OOD checks, and held-out demonstration cases.
4. Build a polished Next.js / React Three Fiber clinical workspace and evidence lab. Use real independently selectable coronary artery meshes; retain visible research disclaimer and honest vessel-level mapping.
5. Verify leakage/scientific validity, prediction and API paths, browser interactions, mobile layout and clean production build. Package one-command startup, Docker, minimal CI, licenses, data/model cards, six-page report, screenshots and a 3-10 minute demo script.

Value filter: work must improve a scored criterion, scientific credibility or demo reliability. No unrelated AI features or enterprise architecture.

Design: reference-image navy, ice blue and teal; quiet white clinical controls flank a dark anatomical viewport. Risk colors encode predicted probability, while artery identity always has a text label. Typography: locally bundled Manrope for interface, IBM Plex Mono for measured values. Signature: actual coronary anatomy, selectable and linked to target-specific explanation and validation.
