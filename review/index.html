04 / 最後的 ML methodology

  1. 最後一輪限縮實驗：LCX/RCA 加入 ExtraTrees 與 RBF SVM，各兩組參數；expanded nested policy 未通過預先設定的 AUC/Brier 改善門檻，四個 deployed model hashes 全部保留。
  2. Research threshold：只用 outer train 的 calibrated 3-fold inner OOF，在固定 .15:.01:.75 grid 最大化 F1；每人平均兩次 probability-minus-cutoff。LCX recall/F1 .840/.641、RCA .868/.631，precision .518/.495；FP 30→93 / 34→101、accuracy 降低。AUC/Brier 不变，workspace 保持 0.50。重用 outer splits 的 development evidence 不是獨立確認。
  3. Threshold 值與 retention decision 分開：前者 training-only，後者使用 pooled outer-test labels，只是 development audit。Evidence Lab 平等展示 Fixed 0.50 與 Exploratory training-selected F1 operating point，不依 retention 結果高亮 winner；不宣稱最佳 threshold 或獨立確認的改善。
  4. 資料：原始 XLSX 的 303 人、59 欄；55 個輸入，無 missing／duplicate rows。一筆 Cath Normal／LAD Stenotic 原始矛盾標籤保留，不自行改成 vessel union。
  5. 切分：seed 2026；5-fold × 2-repeat stratified outer CV；每個 outer train 內 3-fold inner CV 比較六個候選設定。沒有另宣稱一份未參與開發的 external test。
  6. 選模：inner ROC-AUC − 0.25 × Brier；先選每個 family 的參數，再選 family。Headline 評估 nested selection policy；不是 final full-cohort model 的外部成績。
  7. Preprocessing：numeric median imputation + scaling；categorical mode imputation + one-hot。全部在 pipeline 與 training fold 內 fit；無 global feature selection／SMOTE。
  8. Imbalance：Logistic regression 使用 balanced；Random forest 使用 balanced_subsample；XGBoost 使用 regularization。Class weights 只由各 training estimator 計算。
  9. Calibration：predeclared sigmoid，outer train 內 3-fold OOF calibration，ensemble=False；Raw／Isotonic 僅 sensitivity comparison，未用 outer test 選校準方法。
  10. CI：1,000 次 patient-stratified bootstrap，針對 repeat-averaged OOF；conditional on fitted folds，不含重新訓練／選模變異。Fold SD 是 descriptive，因 folds 重疊。
  11. Uncertainty：三 family disagreement + refitted-model min/max。Demo 只取排除此病人的兩個 outer models；新輸入取十個 outer models；不是 clinical confidence interval。
  12. OOD：standardized mixed-feature nearest-neighbor distance，以 cohort leave-one-out distance 的 95th percentile 為界，加上 observed single-feature range。未經外部驗證的 heuristic。
  13. Leakage guard：ml/schema.py 的 LeakageGuard／guard_columns，會拒絕 Cath／LAD／LCX／RCA（含大小寫／常見字元變體），接在 fit／transform 與 API validation；tests/test_validity.py 有真實 guard／fold／prediction checks。
  14. SHAP：對相同 calibrated probability 做 permutation SHAP；background 只來自 training partition；55 個原始 feature coalitions，兩個 local cycles；base + contributions 重建機率至 1e-6。近似且非因果。
  15. Demo honesty：目前八個案例依病人特徵選取，不是 evaluation sample；模型與 SHAP background 排除此病例。改值後仍用排除該 row 的模型；新 profile 使用全 cohort fitted model。
  16. Reliability：四個預先固定案例、四個 target 的 local SHAP seed／computation／training-background sensitivity，量化重疊與幅度，不能概括所有病人。校準六分箱加入人數、descriptive Wilson intervals；Brier bootstrap conditional on fitted predictions。完整 protocol／vectors／fingerprints：experiments/reliability/results.json。
  17. Integrity：checkpoint 比對 data／code／schema／seed／repeats／Python／libraries；API 載入前驗證八個 inference files，含 OOD。輸入來源逐欄追蹤並隨病例匯出；桌面 Chromium integration tests 已接入 CI。

05 / 3D 的實際做法

BodyParts3D 4.0 / DBCLS，CC BY 4.0；human-atlas derivative commit 1c38bf35c254a891200d3cedecfd57abebe83d8d。共 63 個真實 mesh、37,444 triangles、1,071,048 bytes。LAD 21、LCX 6、RCA 29 個 source mesh 各自分組，可獨立選取／上色；不是手畫線或 overlay。DOM 文字標籤只是投影到 mesh centroid。Source names／IDs、license、修改與 hash 位於 manifest 與 ATTRIBUTIONS。

風險映射：每組真實 coronary mesh 的 Three.js material 依該 target calibrated probability 由 teal → amber → coral 上色；等待預測時無虛構機率。可 rotate／zoom／pan／select／X-ray／isolate／expand。沒有 patient-specific scan、lesion coordinates 或 RWMA-to-lesion mapping。
