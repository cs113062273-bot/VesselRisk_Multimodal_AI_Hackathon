Before recording: run `python scripts/start.py`, use the production build at 1440 x 1000 or 1920 x 1080, and pre-run Mixed vessel estimates, Lower CAD estimate and Held-out failure case. Reset to the default mixed-vessel case with no outcome revealed. Read values from the live app if artifacts change. FPS is a live measurement, not a universal performance guarantee.
